# 15. Two-Week Starter Plan & Life Integration

Don’t optimise forever. **Start realistic. Adjust.**

## Day 0 setup (same day you finish this chapter)

1. List subjects + exam dates + top topics  
2. Weekly timetable: **3–5 blocks** of **60–90 min** on school days  
3. Folders + empty **error log** per main subject  
4. Fixed **wake time** + water bottle  
5. Tell family your quiet blocks (negotiate one trade)  

### Every block

5 min review → main active work → 5 min self-test  

### Every Sunday

What worked? What leaked? One practice test scheduled?  

## Week 1 — Build the machine

| Focus | Actions |
|-------|---------|
| Systems | Timetable, folders, error log live |
| Methods | Active recall every block; one timed set if ready |
| Body | Sleep + water + real meals + walk/exercise non-negotiable |
| People | Green allies ok; cut red drama time |
| Review | Sunday: keep / cut / change |

## Week 2 — Raise quality

| Focus | Actions |
|-------|---------|
| Spacing | Re-hit Week 1 weak topics |
| Interleaving | Mix topics in ≥ 2 sessions |
| Exam skill | One longer timed practice |
| Mindset | 5 min process imagery max, then work |
| Tighten | Remove one low-value habit |

## The ongoing loop (for life, not only exams)

```text
Plan week (high-impact first)
  → Protect sleep, water, food, exercise
  → Optional short breath / imagery
  → Execute active methods
  → Log errors
  → Guard social energy
  → Weekly review → adjust
       ↑__________________|
```

## Weekly review questions

1. What improved (scores, speed, calm)?  
2. What leaked (sleep, phone, chat, avoidance)?  
3. Just doing vs procrastination — honest score?  
4. People: who helped, who drained?  
5. One method change + one boundary for next week?

## Mantras worth keeping

> Consistency beats intensity.  
> Kind to people. Strict with the schedule.  
> Sleep is study.  
> Start ugly; improve in motion.  
> Results come from the work you control.

## For parents (one page)

- Ask for **outcomes and timetables**, not only hours  
- Protect **sleep and quiet** more than extra guilt  
- Praise **process** (error log, kept blocks), not only ranks  
- Avoid public comparison with cousins/siblings  
- Your calm is contagious; so is your panic  

## Closing

This guide is “ultimate” not because it lists every trick on the internet, but because it stacks what actually compounds:

**clear targets → honest action → proven study methods → a strong body → wise people skills → character that outlasts one exam.**

Run the two weeks. Then run the loop. Raise the standard each term.

You don’t need a perfect personality.  
You need a **repeatable system** — and the courage to start today’s block.
